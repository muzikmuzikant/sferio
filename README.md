# SFERIO

Private school community platform for Слобідський ліцей №2.

## Development workflow

- `main` — stable branch; changes land here only after explicit approval.
- `beta` — active development and testing.
- Railway project: `sferio`, environment: `beta`.

## Product scope

A school-only social platform with profiles, a shared feed, class communities, roles and permissions, large-scale voting, student self-government, events, notifications, and moderation.

## Privacy and security

This repository is public to support GitHub Pages on the current GitHub plan. Never commit passwords, API keys, tokens, database credentials, private student data, or production environment files. All private data and authorization checks belong on the backend.
